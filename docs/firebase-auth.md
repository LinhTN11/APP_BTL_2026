# Firebase Authentication — T02.01 / F01

USER 02/11/2026 yêu cầu dùng SDK và đã bật Authentication trên Console. BE foundation/FE-test phụ trách tích hợp; visual vẫn theo quy trình phê duyệt riêng.

App dùng Firebase JavaScript SDK modular chính thức (`firebase/app`, `firebase/auth`), hỗ trợ React Native Community CLI, không Expo. Email dùng `createUserWithEmailAndPassword` / `signInWithEmailAndPassword`. Android Google Credential Manager lấy Google ID token; `GoogleAuthProvider.credential` + `signInWithCredential` đổi thành Firebase identity. Không gửi mật khẩu hoặc Google ID token trực tiếp tới API nghiệp vụ.

SDK chỉ giữ auth trong bộ nhớ (`initializeAuth` + `inMemoryPersistence`) cho một lần đăng nhập. App lấy Firebase ID token, gọi `POST /v1/auth/firebase {idToken}`, rồi `signOut` và hủy Firebase app instance kể cả khi exchange lỗi. Phiên API opaque 24 giờ vẫn lưu bằng Keychain/Keystore; không lưu password hoặc Firebase refresh token. Đăng xuất ứng dụng thu hồi phiên API; không đăng xuất tài khoản Google khỏi thiết bị. Hủy account chooser trả về màn hiện tại, không tạo phiên. Nếu đăng ký Firebase thành công nhưng API tạm lỗi, retry bằng đăng nhập với cùng thông tin; không tự xóa tài khoản Firebase vừa tạo.

BE dùng `firebase-admin/auth` trên đúng Admin app/project và `verifyIdToken(idToken, true)` để kiểm chữ ký, issuer/audience, hết hạn, thu hồi token và user disabled trước exchange. Chỉ nhận provider `password` hoặc `google.com`. Firestore transaction ánh xạ UID duy nhất tại `firebaseIdentities/{sha256("firebase:"+uid)}`; tạo user/profile/preferences và session atomically. Không tự link tài khoản cũ hoặc UID khác theo email. App user disabled bị chặn ở mọi request. Thay đổi disabled/revoked ở Firebase được kiểm tại exchange; phiên opaque đã cấp có vòng đời riêng tối đa 24 giờ và cần logout/revoke ở API nếu muốn thu hồi ngay. Không claim refresh, reset password hay email verification UI đã triển khai.

`GET /v1/auth/methods` trả public config `{firebase:{mode,config:{apiKey,appId,authDomain,projectId}},email,google}`. Giá trị `real` nghĩa adapter có cấu hình; provider chưa bật trên Console vẫn lỗi thật từ SDK. `GET /v1/auth/google/config` giữ để UI kiểm khả dụng Google. Các route custom `/register`, `/login`, `/google`, `/google/challenge` trả `410 AUTH_SDK_REQUIRED`, không còn scrypt/direct Google auth production path. Dữ liệu legacy không bị xóa, không migrate hoặc link âm thầm. OTP/demo test giữ gate BE demo và không nằm trong product Login.

BE local cần `FIREBASE_API_KEY`, `FIREBASE_APP_ID`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID`; Google cần thêm `GOOGLE_WEB_CLIENT_ID` đúng Firebase project và Android OAuth package/SHA-1 đúng build. Đây là client public config; Admin credential chỉ nằm ở BE. FE chỉ cần URL API, không cần thêm secret/native Firebase config. Cloud tuyệt đối từ chối `FIREBASE_AUTH_EMULATOR_HOST`; emulator chỉ cho phép loopback với Firestore emulator được chọn rõ. Không bật emulator bằng thiếu config.
