# Yêu cầu BE — ma trận 37 chức năng và backlog có thể giao cho AI

Ngày đối chiếu: 03/11/2026. Phạm vi là rà soát và kế hoạch, không phải lệnh triển khai đủ 37 chức năng trong lượt này.

## Cách dùng

- `ORIGINAL` là năng lực trong `docs/source/yeu-cau-goc.md`; từng dòng giữ nguyên ID F và đủ các ý trong dòng nguồn.
- `USER` là quyết định đã xác nhận: React Native Community CLI; Cloud Firestore qua Admin SDK là DB chính; cloud runtime dùng dữ liệu thật; demo/seed chỉ ở emulator được chọn rõ; phần miễn phí làm thật khi đủ điều kiện, phần trả phí mô phỏng có nhãn; không dùng SQLite.
- `PROPOSAL` là cách nghiệm thu/giới hạn cần duyệt trước phase liên quan. Không biến đề xuất hoặc câu hỏi mở thành quyết định nghiệp vụ.
- Trạng thái bên dưới dựa trên mã và bằng chứng đã có trong repo, không phải kiểm thử mới của tài liệu này. “Chưa hoàn tất” nghĩa là còn thiếu ít nhất một năng lực gốc, provider hoặc bằng chứng nghiệm thu; đọc cột gap để phân biệt thiếu code BE với QA/FE còn mở. Các acceptance gắn PROPOSAL là đề xuất, không tự làm tăng phạm vi gốc.
- Cloud evidence cốt lõi được ghi trong [QA dữ liệu thật](../qa/production-real-data-2026-11-02.md); discovery/GPS trong [QA bán kính](../qa/discovery-radius-2026-11-02.md); chat trong [QA chat](../qa/chat-audit-2026-11-03.md). Cloud không có fixture runtime. Không dùng test emulator để thay cho xác nhận cloud; không ghi/seed/xóa cloud trong lượt rà soát này.
- Mã hiện hành được chia tại `apps/api/src/firestore/{app,firebase-auth,profiles,media,matching,chat,safety}.ts`; contract thực tại `docs/api/openapi.yaml`, `packages/contracts/src/index.ts`, `docs/08-hop-dong-api-va-du-lieu.md`. Roadmap ban đầu có nhiều đường dẫn `apps/api/src/modules/...` chưa khớp với cấu trúc Firestore hiện hành.

### Lệnh kiểm chứng và môi trường

- Bộ BE emulator hiện có: `npm run test:firestore` (chỉ chạy với Firestore Emulator được chọn rõ); không trỏ bộ này vào cloud production.
- Kiểm tra liên workspace khi cần: `npm run typecheck`, `npm run lint`; xem scripts root trước khi giao lệnh cũ theo roadmap.
- Kiểm tra đọc cloud dùng `npm run firestore:check`; không chạy seed/reset fixture, tài khoản test hay lệnh ghi test lên cloud. Roadmap này không cấp quyền ghi cloud.
- Các đường dẫn `npm run test:api -- ...` trong T06–T10 của `docs/04-ke-hoach-trien-khai.md` là **tên suite dự kiến cho tương lai**, không chứng minh module/lệnh đã tồn tại. Khi triển khai, thêm script/test thực và cập nhật OpenAPI/checklist cùng task.
- Không ghi kết quả fixture/provider emulator thành hoạt động provider thật; API và app phải phân biệt `demo` với `unavailable`.
