# APP-Cuoi-Ky — app hẹn hò React Native

Thư mục chuẩn bị thiết kế và triển khai cho nhóm **1 BE + 1 FE**, ưu tiên Android. Backend cần ưu tiên hoàn thành trong ngày 01/11/2026; FE tích hợp trong một ngày riêng.

**Trạng thái hiện tại:** docs, prototype và skills cục bộ. Chưa có ứng dụng/server; chưa thể chạy `npm ci` hoặc `npm run demo` trong repo này.
